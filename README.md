# TWRP Recovery Builder for Vivo 1803 (PD1732F_EX)

Automated GitHub Actions builder for Team Win Recovery Project (TWRP) 3.x targeting the Vivo 1803 / Y81 (PD1732F_EX, MediaTek MT6765 Helio P35).

## Device Specifications
- **Device:** Vivo 1803 / Vivo Y81
- **Model Code:** PD1732F_EX / PD1732DF_EX
- **Board:** `k62v1_64_bsp`
- **Chipset:** MediaTek Helio P35 (MT6765)
- **Architecture:** ARM64 (`arm64-v8a`)
- **Base OS:** Android 8.1 Oreo (Funtouch OS 4.0)

## How to Build
Click **Actions** -> **Build TWRP Recovery for Vivo 1803** -> **Run workflow**.

Once finished, the flashable `recovery.img` will be available under **Releases** and **Artifacts**.
